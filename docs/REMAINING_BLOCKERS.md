# Remaining blockers

- Hosted Supabase, SMTP, an approved HTTPS domain and platform staff provisioning need verification before a customer pilot.
- Confirm data hosting and transfer, retention and deletion, incident response and privacy obligations with qualified reviewers. Validate a restore from the selected backup process.
- Branch-level access, private files, live public listings, secure uploads, CSV import/export and billing entitlements require further implementation.
- Complete responsive and accessibility testing across the full workspace and measure production Core Web Vitals after hosting is approved.

See the [enterprise transformation report](ENTERPRISE_TRANSFORMATION.md) for local evidence and the [deployment guide](DEPLOYMENT_GUIDE.md) for configuration details.
