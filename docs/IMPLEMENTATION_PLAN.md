# Implementation plan

## Phase 1 — core MVP
- Landing page and sales content
- Auth flow and workspace onboarding
- Tenant-aware dashboard and workspace switching
- Property portfolio CRUD and listing publication states
- Contact CRM and the sales pipeline
- Reporting and pricing workflow
- Platform admin visibility

## Phase 2 — landlord management
- Buildings, units, tenant profiles, lease records and rent payment tracking
- Balance management and statements
- Maintenance and occupancy workflows

## Phase 3 — optional automations
- WhatsApp business link adapter
- Email service abstraction
- Map display and AI-assisted enquiry support behind feature flags

## Verification loop
- Validate each batch with lint, TypeScript checks and focused tests
- fix defects before moving to later work
- update checkpoint and docs after milestones
